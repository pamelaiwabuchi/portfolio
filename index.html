GesTec — Sistema de Gestão de Ordens de Serviço (SGOS)

Sistema desenvolvido pela equipe GesTec para a empresa parceira ALTAVE, com o objetivo de centralizar, estruturar e rastrear o fluxo de solicitações operacionais e projetos de implantação: cadastro de clientes e projetos, ordens de serviço por departamento, controle de status, prazos de SLA, notificações e logs de auditoria.

Projeto desenvolvido com Scrum em 3 sprints (set-nov/2026), utilizando React, TypeScript, Node.js/Express, PostgreSQL (Supabase) com Prisma, JWT e Swagger.

Atuei como desenvolvedora no registro de horas nas ordens de serviço: criação da tabela de lançamentos de horas, registro de horas na O.S. com exigência de horas na troca de status e listagem dos lançamentos com total. Também adaptei o banco do sistema para MySQL na disciplina de Banco de Dados Relacional, com modelagem, functions, procedures, triggers e views.

Projeto Radar Cidadão

Os dados sobre a atuação dos Deputados Federais são públicos, mas difíceis de interpretar. O Radar Cidadão transforma esses dados em informações simples e comparáveis, para que o cidadão possa decidir seu voto com base em dados reais.

Minha atuação, do dado bruto ao indicador:

  • Coleta: extração de dados da API pública da Câmara dos Deputados.
  • Modelagem: modelagem conceitual e lógica do banco de dados MySQL (tabelas, chaves primárias/estrangeiras e relacionamentos), implantado em instância AWS.
  • Carga: scripts SQL para população e carga inicial dos dados.
  • Análise: criação do Índice Geral de Desempenho dos Deputados, fórmula que avalia o desempenho de cada parlamentar e se tornou o principal diferencial do projeto.

Projeto do 1º semestre, desenvolvido com Scrum em equipe de 9 pessoas.
